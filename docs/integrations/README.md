# Integrations

Integration guidance for module teams is in the **OAN Messaging integration handoff**
pack (`DEV-HANDOFF/` in the developer package), and the design for SMS and Telegram is
the **OAN Channels Specification v2.0** (`CHANNELS-SPEC/`).

| Here | Contents |
|---|---|
| `examples/` | Request, response, status and error bodies, validated by `tests/clients/test_examples_api.py` |
| `rapidpro.md` | Future scope only: a RapidPro-to-OAN SMS bridge, not planned for Phase 1 |
